Play LAN-only games with friends,
from different houses.

LANLink creates a private virtual network between your PCs over the internet — your old games think everyone is on the same Wi-Fi. No port forwarding. No accounts. Nothing to install.

Install in 3 steps (every player, once)

1
Install Python from python.org — on the first setup screen tick “Add python.exe to PATH”.
2
Download & unzip using the blue button above (or clone the repo) — Desktop or USB stick, anywhere.
3
Allow the firewall popup the first time you run it (tick Private networks → Allow access).

Start a game night

1
Everyone double-clicks start-player.bat, types their name, presses Enter. A page opens: http://127.0.0.1:32441.
2
Check the other players appear, then click Ping — anything under 100 ms is great.
3
One person hosts the game in LAN / Local multiplayer. Others join with the host's virtual IP (10.242.x.y from the page). Play! 🎉
1
One friend double-clicks start-signaling.bat and leaves the window open — this is the “meeting point” that introduces players (game data still flows directly PC-to-PC).
2
That friend shares their address (ipconfig → IPv4, or google “what is my ip”) and an invented Room Code like HALO-42.
3
Everyone runs start-player.bat, pastes http://THAT-ADDRESS:32440 as the server, enters the same Room Code — then plays exactly like a LAN game.

Go backend (single static binary), Python reference node, encrypted UDP mesh (HEADER(20)+CT+TAG(8)), UDP hole-punching via STUN, room-code signaling. Full protocol spec in the repo README.

Not working? 30-second fixes

No players appear

Same Room Code on all PCs (capitals matter) · same signaling address · firewall allowed Python · wait 30 seconds.

Ping says “timeout”

Firewall blocked it — allow Python through, keep both black windows open.

“address already in use”

An old window is still running — close all black LANLink windows, wait 10 s, retry.

Game can’t find the host

Join with the host’s virtual IP (10.242.x.y from the page), not their normal IP, and host in the game’s LAN mode.
